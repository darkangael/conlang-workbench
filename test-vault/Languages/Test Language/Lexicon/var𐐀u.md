# var𐐀u

Permanent regression fixture for testing lexical words containing a Unicode
letter outside the Basic Multilingual Plane.

The medial character is U+10400 DESERET CAPITAL LETTER LONG I.

This entry exists so cursor-under-word lookup and rendered-text hover behavior
can be runtime-tested against a known dictionary entry.

Do not normalize, replace, or simplify the unusual character merely to make
the fixture easier to type.
