# Attribution

Conlang Workbench began as a fork of **Made Up Words**, an Obsidian plugin created by Josh P and developed through the Obsidian TTRPG Community.

The original project provided the foundation for dictionary storage, indexing, lookup, inflection handling, phrase handling, and related Obsidian integration from which Conlang Workbench began its development.

Conlang Workbench is intended to grow beyond that original scope into a broader workbench for constructed-language creation and linguistic documentation.

## Original Project

**Made Up Words**  
Obsidian TTRPG Community

Conlang Workbench preserves the Git history of the original project and remains linked to its upstream repository.
